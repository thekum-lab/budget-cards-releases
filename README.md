# Budget Cards — Releases

This repository contains the official release binaries for **Budget Cards**, a privacy-first personal finance app for desktop.

> **Source code is private.** This repo exists solely to distribute signed installers publicly.

---

## Download

Visit **[budgetcards.se](https://budgetcards.se)** for the latest version, or grab a file directly from the [Releases](https://github.com/thekum-lab/budget-cards-releases/releases) tab.

| Platform | File | Notes |
|---|---|---|
| macOS · Apple Silicon | `Budget.Cards_x.x.x_aarch64.dmg` | M1, M2, M3, M4 |
| macOS · Intel | `Budget.Cards_x.x.x_x64.dmg` | x86_64 |
| Windows | `Budget.Cards_x.x.x_x64-setup.exe` | Recommended |
| Windows (enterprise) | `Budget.Cards_x.x.x_x64_en-US.msi` | MSI for IT/managed installs |
| Linux · AppImage | `Budget.Cards_x.x.x_amd64.AppImage` | Universal, no install needed |
| Linux · Debian/Ubuntu | `Budget.Cards_x.x.x_amd64.deb` | |
| Linux · Fedora/RHEL | `Budget.Cards-x.x.x-1.x86_64.rpm` | |

Replace `x.x.x` with the version number from the release you are downloading.

## About the app

- Tracks income and expenses by category, month, and currency
- Data stored locally in SQLite — no account, no cloud, no subscription
- 47 UI languages built in
- Optional AI insight: bring your own OpenAI / Claude / Groq / Ollama key — or skip AI entirely
- Export to CSV, JSON, Excel

**Support:** support@budgetcards.se
